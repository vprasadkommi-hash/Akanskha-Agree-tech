# Background Video

Place your hero background video at:
```
public/hero-video.mp4
```

And optionally a poster image (shown before video loads) at:
```
public/hero-poster.jpg
```

The video should be:
- MP4 format (H.264 encoded for browser compatibility)
- Short loop (10-30 seconds)
- Compressed for web (keep under 5MB if possible)
- Agriculture/farming themed

If no video is present, the hero section will show a black background with the overlay gradient. You can also replace the video source in `src/components/Hero.tsx` with a different URL or file.
